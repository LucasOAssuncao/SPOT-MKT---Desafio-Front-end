# 🚀 SpotMKT Dashboard

Uma aplicação desenvolvida com **Next.js**, **TypeScript** e **TailwindCSS**, como parte de um desafio técnico. O objetivo foi criar uma experiência de login e dashboard com foco em **boa usabilidade (UX)**, **design responsivo** e **organização do código**.

## 🧠 Objetivo

Criar uma aplicação simples com duas telas principais:

1. **Login** com validação de credenciais fixas (sem backend).
2. **Dashboard** ilustrativo com informações fictícias, simulando o painel de um cliente de agência de marketing digital.

---

## 🛠️ Tecnologias Utilizadas

- [Next.js 13+ (App Router)](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [TailwindCSS](https://tailwindcss.com/)
- **IA** para auxiliar no desenvolvimento e refinamento de ideias

---

## 💻 Funcionalidades

### 🔐 Tela de Login

- Login simples e validado no front-end
- Layout clean e responsivo
- Credenciais fixas:
  - **Usuário:** `spotmkt`
  - **Senha:** `123`

### 📊 Painel Principal (Dashboard)

- Interface fictícia com cards e dados simulando:
  - Métricas de campanhas
  - Insights e notificações
  - Calendário de ações
  - Dados do usuário e configurações
- Design responsivo e adaptado para mobile e desktop
- Sem funcionalidades reais (somente visual/layout)

## 📦 Como rodar o projeto

```bash
# 1. Clone o repositório

# 3. Rode o servidor de desenvolvimento
npm run dev
O app estará disponível em: http://localhost:3000
